# v3.6.0 —— 更新检查改为定时触发，新增居中更新对话框

## 检查时机

自动检查的节奏从「启动 + 每 6 小时」改为「**启动后 20 秒 + 每天 09:00**」
（本机时间）。

- 09:00 与每日简报、邮件简报是同一个作息，提示落点可预期；每 6 小时一次会
  让提示出现在一天中的任意时刻，且随开机时间在不同机器上各不相同
- 发版频率低于每天一次，更高的检查频率不会更早发现新版本，只会增加向 GitHub
  发出的未认证请求（该额度为每小时 60 次）
- 启动后留 20 秒，让窗口、悬浮球和本地服务先完成初始化

新增 `updater.until_daily(hour)` 计算距下一个整点的秒数，下限 60 秒 —— 避免在
整点当秒空转，也覆盖夏令时切换当天算出负值的情况。

## 居中更新对话框

发现新版本时弹出一个模态对话框，取代此前只有「右下角弹窗 + 页面顶部横幅」的
提示方式。三层提示强度递减：

| | 出现时机 | 操作 |
|---|---|---|
| 居中对话框 | 一个版本只弹一次 | 立刻更新 / 稍后手动更新 / 跳过这个版本 |
| 右下角弹窗 | 同上，数秒后消失 | 点击跳转到横幅 |
| 页面顶部横幅 | 持续显示 | 随时点「更新并重启」 |

对话框内容：

- 版本跳转（`v3.5.2 → v3.6.0`）与发布日期
- 包的大小，以及「你的邮件、对话、课件、设置都不动」——这两句此前在
  `window.confirm` 里，现由对话框承担，因此点「立刻更新」不再二次确认
- **从当前版本到最新版之间每一版**的更新说明，区域可滚动

弹出条件（与后端 `_tell_update` 同一套判定，避免两处各弹各的）：

- 仅对已发布 Release 的版本弹出；源码版的新提交由横幅呈现
- 一个版本只弹一次，记录在 `prefs.updSheetSeen`，重启应用也不再弹
- 点过「跳过这个版本」的版本不再弹
- 设置中关闭「有新版本时提醒」（`updateToast`）后，对话框与右下角弹窗一并关闭
- 设置面板或作业详情浮层打开时不抢占；更新任务进行中不打断

Esc 与点击遮罩可关闭，关闭等同于「稍后手动更新」。

## 验证

无头环境下驱动真实前端，覆盖 8 条分支并中英双语各跑一次：自动弹出、按钮文案、
说明分版渲染、「稍后」关闭、同版本不重复弹、更高版本再次弹出、Esc 关闭、
跳过的版本不弹、关闭提醒开关后不弹、无新版本不弹。均通过，无 JS 报错。

## In English

**Update checks are now scheduled; a modal dialog announces new versions.**

The automatic check moved from "on start, then every 6 hours" to **20 seconds
after launch, then daily at 09:00 local time** — the same schedule as the daily
and mail briefs, so the prompt lands at a predictable time. A six-hour interval
placed it at an arbitrary hour that also varied per machine, and since releases
are less frequent than daily it did not surface updates any sooner; it only
added unauthenticated GitHub requests against the 60-per-hour quota. A new
`updater.until_daily(hour)` computes the delay, floored at 60 seconds to avoid
spinning on the hour and to absorb DST transitions.

When an update is found, a **centered modal** now appears in addition to the
existing corner toast and page banner. It shows the version jump and release
date, the download size, the note that mail / chats / course files / settings
are untouched, and the release notes for **every version between yours and the
latest**. "Update now" starts immediately (the dialog replaces the former
`window.confirm`); "Later" dismisses it while the banner stays; "Skip this
version" suppresses it permanently for that version.

It appears once per version (persisted in `prefs.updSheetSeen`), only for
published releases, never for skipped versions, never while the settings panel
or another sheet is open, and not at all when the "notify me about updates"
setting is off. Esc and a backdrop click both dismiss it.

Verified headlessly against the real frontend across 8 branches in both
languages, with no JS errors.
