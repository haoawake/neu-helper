# v3.2.3 —— 换主题后小球真的会变，弹窗也跟上像素风

## 1. 换了主题，收成小球还是旧的那颗

球的外观是在 `set_look()` 里更新的，而它只在**直径、深浅、缩放、动画**这四样
变了的时候才重画。换主题这四样一个都不变 —— 配色在另一个模块级开关里。

窗口开着的时候球是隐藏的、动画定时器也不转，所以它就一直留着上次那张位图。
等你收成球，看到的还是换主题之前那颗。

现在 `set_theme()` 会**返回"这一下有没有真的换"**，换了就强制重画一次。

每一档的球本来就各不相同：

| | |
|---|---|
| 浅色 / 深色 | 蓝紫流光的玻璃泡 |
| NEU | 两支红在里面转 |
| 海边 | 装着半球水的玻璃球，浪会晃 |
| 像素 | 我的世界的草方块 |

## 2. 右下角的弹窗在像素档下还是圆角柔光

界面那边整套都换成方角硬投影了，弹窗没跟上就很割裂。现在这一档的卡片是：
**直角 + 一圈墨色描边 + 右下角一块实心偏移投影**。

修的过程里挖出一个真 bug。卡片的圆角矩形距离原来是这么算的：

```python
dx = max(x0 + r - x, 0, x - (x1 - 1 - r))
d  = sqrt(dx² + dy²) - r
```

这个式子在矩形**内部恒等于 `-r`** —— 它能工作完全是因为"圆角半径一定大于 1"，
判断内部用的是 `d <= -1`。圆角一归零（正是像素档要的），内部就全是 0，
整张卡片一个像素都画不出来，只剩一块孤零零的投影。

换成标准写法之后内部给的是到最近边的真实距离，`r=0` 照样对，顺带让描边可以直接
写成"距离边缘 2px 以内"。圆角那几档重新渲染确认过，长相没变。
