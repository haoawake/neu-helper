# v3.2.0 —— 两个换画风的主题:海边、像素

主题现在六档：跟随系统 / 浅色 / 深色 / NEU / **海边** / **像素**。

前四档是换色。**后两档是换画风** —— 圆角、投影、模糊、缓动、字体一起变。

## 海边

中午的沙滩：晒白的细沙、浅水的绿松石、一点落日橘。

- 圆角**加大一档**（14 → 18px）。界面上的"可爱"，八成就是圆角给的
- 投影**偏青而不是灰**。中性灰压在暖沙上会发脏，青的像水面反光
- 玻璃留着 —— 海边本来就是通透的
- 弹性缓动更明显一点，但时长没加长：轻盈是"快而软"，不是"慢而飘"

> 第一版调得太克制，出来是一片米白，「明媚」没了。浅色底上的大面积柔光比深色底
> 吃亏 —— 同样的 alpha 压在白上几乎看不见，所以这一档的背景光比别的主题都浓。

## 像素

这一档是**反玻璃**的：半透明 + 模糊 + 柔和投影，正好是像素画风的反面。

- 圆角**全部归零**，包括那些写死 `50%` / `999px` 的地方（开关的圆头、状态点、
  胶囊按钮）
- 投影换成**实心偏移块** `4px 4px 0`。这是像素 UI 最标志性的长相
- 模糊关掉、表面全不透明
- 缓动换成 `steps()` —— 动效走格子，不是丝滑插值
- 全站等宽字，面和控件描一圈墨蓝边
- 配色走经典掌机那一路：奶油底、墨蓝线、一支正红

> **"关掉模糊"这件事没法写在 CSS 里。** 玻璃不透明度和模糊半径是内联写在
> `:root` 上的（滑块要能实时预览），内联样式压过任何 CSS 规则。所以这两个值
> 由 `app.js` 的 `THEME_LOCK` 在这一档钉死，滑块摆哪儿都不算数。
>
> 真正的点阵字没有用：得打包一份字体（这个项目不联网，也不想为此多背几百 KB），
> 中文点阵字更难找。等宽 + 方角 + 硬投影已经足够"游戏机"。

## 悬浮球和弹窗也跟着换

它们是逐像素自绘的、读不到 CSS，所以每一档都单独给一份配色。像素那档的球是
**实心的** —— 透明感和柔和高光正是这套画风要避开的东西。

## In English

Two new themes that change the **art style**, not just the palette.

**Beach** — noon at the shore: bleached sand, shallow-water turquoise, a touch of
sunset orange. Corners get rounder (14 → 18px), shadows turn teal instead of grey
(neutral grey over warm sand looks dirty), the glass stays because a beach is
meant to feel airy, and the spring easing bounces a little more without getting
slower.

**Pixel** — the anti-glass theme. Every corner squared off, shadows become solid
offset blocks (`4px 4px 0`) instead of blur, backdrop blur disabled, surfaces fully
opaque, easing switched to `steps()` so motion moves in notches, monospace
everywhere, ink-blue outlines, and a handheld-console palette: cream, ink, one red.

Turning the blur off could not be done in CSS — glass opacity and blur radius are
written inline on `:root` so the sliders can preview live, and inline styles beat
any stylesheet rule. They are pinned in JS for this theme instead.

The floating orb and the corner notifications follow both themes too; they are
drawn pixel by pixel and cannot read CSS, so each theme carries its own palette.
