# v3.5.2 —— 邮件排序：盯着的置顶，已读也按重要程度

三条，都在邮箱页。

## 1. 盯着的邮件永远在最上面

盯住一封信（卡片右下角那颗 ☆）的意思就是"这件事我还没处理完，别让它沉下去"。
所以它现在是**所有排序的第一顺位** —— 按时间排、按重要程度排、从旧到新排，
盯着的都在最上面。

标了「完成」之后就退出置顶，回到普通的排序里。

测的时候刻意挑了**最不起眼的一封**来当盯着的那个：已读 + 噪音级 + 全场最旧。
它要是能排到第一，那就只可能是这条规则起的作用。

## 2. 按重要程度排序时，已读的也按重要程度排

上一版把已读**一律折成 0 级**，于是"按重要程度排"对已读那一段完全失效 ——
翻到已读部分就变成纯时间序了，而那恰恰是回头找一封要紧旧信的时候。

现在是四层：

```
盯着的  >  未读 / 已读  >  级别  >  时间
```

「未读 > 已读」那一层保持不变（已读的「要紧」仍然比不过未读的「普通」——
看过了就等于知道了，不该把没看过的挤下去），但**两堆各自内部都按级别排**。

## 3. 点「盯着 N 封」只看盯着的

顶栏那句话原来只是个数字。可"盯了几封"之后第一个念头就是"哪几封"——
数字旁边不给入口反而添堵。现在点一下就只看这几封，再点回到全部；开着的时候
它会用强调色标出来，不至于让人对着一个筛过的列表发懵。

它也从 `<span>` 换成了真正的 `<button>` —— 既然能点，就得能用键盘走到、
读屏也念得出来。

搜索结果用的是**同一套口径**（盯着的 > 未读/已读 > 级别 > 时间），
不会出现"列表里置顶、一搜就乱"。

## In English

**Three fixes to mail ordering.**

1. **Watched mail always sorts first.** Starring a mail means "I have not
   finished with this — do not let it sink", so it is now the top key in *every*
   sort order, not just one. Marking it done releases the pin. (Tested with the
   least prominent mail possible as the pinned one — read, noise level, oldest
   of all — so if it lands first, only the pin can have done it.)
2. **Sorting by importance now applies to read mail too.** The previous version
   folded read mail to level 0, which made "sort by importance" useless for
   exactly the case where you need it: going back to find an important older
   mail. The order is now four layers — watched > unread/read > level > time.
   Unread still outranks read (a read *Important* still loses to an unread
   *Normal*), but each of the two groups is ordered by level internally.
3. **Clicking "Watching N" shows only those.** It used to be a bare number, but
   the next thought after "N watched" is "which ones". Click to filter, click
   again to go back; it is highlighted while active. It also became a real
   `<button>` rather than a `<span>` — if it is clickable it has to be reachable
   by keyboard and readable by a screen reader.

Search results use the same ordering, so nothing jumps around when you search.
