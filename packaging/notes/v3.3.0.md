# v3.3.0 —— 收放动画的顺序、浮窗能关了、英文补齐

五件事，都是用着用着发现的。

## 收成球是「先缩小、再变球」，不是「整屏先变一次」

三态切换（完整面板 ↔ 对话框 ↔ 悬浮球）都有一个共同的毛病：**页面布局在窗口
还是满尺寸的时候就换掉了**。三栏瞬间重排成一栏，然后窗口才开始缩 —— 人眼读
到的是「整个屏幕先变了一次，然后才缩小」，动画像被吞掉了一样。

现在换布局这一步推迟到内容淡出之后（110ms 的淡出跑完再换，比它多留 10ms），
重排发生在看不见的时候。后端那一侧也补齐了：完整面板 ↔ 对话框原来是收到请求
立刻开始形变，不等页面淡出 —— 和收球那条路一样先等 110ms。

关了动画的话不等，立刻换。

## 悬浮球上弹出来的备忘录，现在能关、能拖

那一态整扇主窗口就是备忘录，而标题栏（拖拽区和关闭按钮都在上面）是藏起来的。
结果是：

- **关不掉。** 自动收起看的是「指针离开了没」，可指针一旦在浮窗里点过一下，
  它就成了前台窗口 —— 收起的判定从此认定你还在用它，永不收起
- **拖不动。** 压根没有拖拽区

补了一条自己的标题条：左边「备忘录」四个字是拖拽区，右边一个 ✕。**拖过之后
会自动钉住** —— 不钉的话你把它挪到别处、手一移开它就没了，那这一拖等于白拖。

## 学业页左栏那条课程表入口去掉了

日程早就升成顶层页（学业 / 邮箱 / 日程三个并列），左栏那条小横条是它还埋在
子视图里时候的入口，现在只是重复。顶层导航上那个数字（今天还剩几件事）保留。

## 英文补齐

上一版切英文之后还剩一批中文，都是**后端送过来的**字符串 —— 照着
`index.html` 和 `app.js` 找是找不到的：

- 仪表盘统计：未提交待办 / 学分课 / 待拿分值
- 作业紧急度：已过期 / 今天到期 / 紧急 / 临近 / 充裕 / 无期限
- 邮件级别：要紧 / 留意 / 普通 / 噪音 / 没过目
- 邮件的 16 个标签，连同悬停能看到的那份定义
- 后端给的日期「09月22日 周二」，以及日程里光秃秃一个「周三」

顺带修了三处翻译本身的毛病：

- `2026-09-22(今天)` 原来翻成 `2026-09-22( (today))` —— 规则里那对括号忘了
  转义，被正则当成了捕获组
- `数据抓取于 …` 翻成 `数据fetched …`，只吃掉了后半截
- 链接前面那个小标签（表单 / 职位 / 会议…）原来是小写，和同一排的
  `Canvas`、`PDF` 挤在一起很扎眼，统一成首字母大写

右下角那条原生弹窗也跟着语言走了。它不是网页（自己画的一张位图），
DOM 那套翻译够不着，所以新邮件、新作业、有新版本这几条在 Python 里分了岔。

## 已读的邮件不再参与重要度排序

「按重要程度排」的时候，已读的一律按 0 级算 —— 看过了就等于知道了，再让它凭
级别顶在最前面，只会把没看过的挤下去。已读的仍然在列表里，只是退到所有未读
后面，彼此之间按时间新旧排。

## In English

**Five fixes.**

1. **Collapse and expand animate in the right order again.** The page layout
   used to switch while the window was still full size — three columns snapping
   to one, and only then the window starting to shrink. It read as "the whole
   screen changes, then it shrinks." The relayout now waits until the content
   has faded out, and the backend waits for that fade before resizing the
   panel ↔ chat window (it already did for the orb).
2. **The memo popover above the floating orb can be closed and dragged.** That
   state hides the whole title bar, which is where the drag region and the close
   button live — so there was no way to do either, and the auto-hide never fired
   once you had clicked inside it (that made the window foreground, which the
   auto-hide reads as "still in use"). It now has its own slim bar: drag on the
   left, ✕ on the right. Dragging pins it, otherwise moving your mouse away
   would make it vanish right after you placed it.
3. **Removed the timetable strip from the Study page's left column.** Schedule
   is a top-level page now; the strip was a leftover entry point.
4. **English is complete.** The strings that were still Chinese all came from
   the backend: dashboard stats, assignment urgency, mail levels and all 16 mail
   tags (plus their hover definitions), and the date format. Also fixed three
   translation bugs of its own, and the desktop toast now follows the language
   too (it is a bitmap, not a web page, so it needed its own path).
5. **Read mail no longer counts toward importance sorting.** Sorted by
   importance, read mail is treated as level 0 — you have seen it, so it should
   not push unread mail down. It stays in the list, below everything unread.
