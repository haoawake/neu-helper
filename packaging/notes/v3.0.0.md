# v3.0.0 —— 中英双语，外加新图标和 NEU 主题

从 2.0.7 一路攒到这里（中间 v2.0.8–v2.1.3 没发包，都在这一版里）。

## 1. 中英双语

设置 → 外观 → **语言**：中文 / English。切过去之后，界面**和 Claude 的回答**
一起变英文 —— 简报、对话、邮件摘要、抽出来的日程标题，新生成的都跟着走。

两套机制分开做的：

| | 在哪儿 | 怎么做的 |
|---|---|---|
| 界面 | `gui/i18n.js` | 表按**中文原文**索引，翻译发生在 DOM 边界（一个 MutationObserver） |
| 模型 | `applang.py` | 给五处 prompt 末尾各追加一句语言要求：对话、每日简报、邮件简报、邮件过目、课表抽取 |

> 切语言会刷新一次页面 —— 表是单向的，往回切需要反查，而反查在「两句中文翻成
> 同一句英文」时是二义的。刷新拿到一份干净的 DOM，动态内容本来就是从后端重新
> 取的，什么都不丢。
>
> **已经生成过的内容不回溯翻译**：过往简报、邮件摘要、之前抽出来的课表标题，
> 是当时那门语言写的就一直是那门语言。

## 2. 新图标 + NEU 主题

应用图标换成了 NEU Helper 自己那张（黑底、红白的 N、机器人）。标题栏左上角那个
纯色小圆点也换成了它 —— 窗口里和任务栏上现在是同一个东西。

主题多一档 **NEU**：校徽的黑白红。它不是第三种明暗，是深色的一张皮 —— 底子仍是
那套验过对比度的深色值，只把蓝整体换成红。桌面上那颗悬浮球和右下角的信息弹窗
都跟着换。

> 红当强调色有个绕不开的地方：官方那支 `#C8102E` 压白字很稳，但它自己当文字压在
> 近黑底上只有 3.3:1，读不了。所以用亮一档的 `#ef2d47`，和深色主题那支蓝
> `#4f97ee` 亮度相当 —— 两边的取舍是同一个。

## 3. 对话：能复制了，自己说的话能改了重发

- 每条消息底下停一下鼠标，有**复制**（抄的是 markdown 原文，不是渲染后的样子）
- 自己发的那条多一个**编辑** —— 改完重新发一次，这条以下的问答一起作废
- **划选一段也能复制**：右键有菜单（复制 / 复制整条 / 全选这块；输入框里是
  剪切 / 粘贴 / 全选），Ctrl+C 照常
- 简报栏右上角也有一个复制，整份抄走

> 右键菜单是自己画的。pywebview 起 WebView2 的时候把自带的右键菜单跟着 debug
> 一起关掉了，不补一个的话，选中之后根本没有「复制」这个入口。

「编辑重发」在后端是**换一条时间线**：Claude Code 的会话没法回退，所以存档砍到
那一条之后会重开一段会话，把剩下的前文拼成 `<以往对话>` 一起发过去。上下文不丢。

## 4. 日程：删掉的东西有回头路了

这条是踩出来的。自动抽出来的课时删掉之后，它从格子里彻底消失 —— 而条目 id 是
按内容算的，**重新解析回来的还是同一个 id、照样被那条删除记录压住**。于是从用户
那头看就是「点多少次重新解析都没用」，像解析坏了。

现在：

- 日程页底下常驻一条「N 条被你删掉了」，逐条列出来，可以单独恢复或者全部恢复
- **手动点「重新解析」= 真的重建一次**，删掉的一并放回来（改过的名字和时间不动）。
  每小时那次自动保鲜不会这么干 —— 背着人把你删掉的东西请回来更糟
- 状态栏跑完会说一句「放回了 N 条你删掉的 · M 门课源文没变，沿用上次的」，
  不再是点完毫无反应
- 删除本身改成点两下确认，它就贴在「保存」旁边

## 5. 邮件日程：几封信说同一件事，只画一条

快递最典型：一封「今天送到」，一封「15:00–16:00 送到」。判断分两步 —— 先看是不是
落在同一天的同一个时段，再看两个标题是不是在说同一件事（标题拆成碎片比重合度：
英文按整词、中文按相邻两字）。合并后内容用最新那封的，但**时刻取更具体的那份**。
点开那个块能看到参与合并的每一封信。

宁可少合不可错合：同一天的「面试 10:00」和「面试 14:00」时段不相交，保持两条。

## In English

**NEU Helper is now bilingual.** Settings → Appearance → Language → English
switches the whole interface **and Claude's answers** — briefings, chat, mail
summaries and newly extracted schedule entries all follow. Content generated
before the switch keeps the language it was written in.

Also in this release: the new app icon and an **NEU** theme (the crest's black,
white and red — the floating orb and the corner notifications follow it too);
copy buttons and edit-and-resend in chat, plus a right-click menu so you can
select any passage and copy it; deleted schedule entries can be restored
(re-parsing used to look broken because a content-hashed delete record kept
suppressing them); and mail events that describe the same thing are merged into
one block you can open to see every message behind it.

**Windows install fix worth calling out:** on an English Windows the setup
script used to die because a progress line could not be encoded in cp1252.
If an earlier version refused to install for you, this one should work.

Download `NEU-Helper-win-x64.zip` below, unzip anywhere, run `setup.ps1` once.
