# v3.1.1 —— 点弹窗不该把窗口缩小

## 现象

窗口开着完整面板，点一下右下角的弹窗 —— 它立刻缩成了小对话框。

## 为什么

点弹窗那一步无条件执行：

```python
apply_mode(restore_mode())
```

而 `restoreMode` 记的是**「点悬浮球该还原成哪个形态」**（默认 `chat`）。
这个还原只在**收成球**的时候才有意义：窗口是隐藏的，得把它变回来。

可窗口本来就开着的时候，同一句话就变成了「把它切成 chat」—— 你的完整面板被
硬压成小对话框。弹窗越有用，这一下越烦。

## 改了什么

分两种情况：

| 当时的状态 | 点弹窗做什么 |
|---|---|
| 收成了悬浮球（窗口隐藏） | 还原成上次那个形态 —— 原来的行为，对的 |
| 窗口已经在眼前 | **只把它抬到最前面，尺寸一个像素都不动** |

跳转（打开那封邮件 / 滚到更新横幅）两种情况下都照做。

---

## In English

Clicking the corner toast used to run `apply_mode(restore_mode())` unconditionally.
`restoreMode` means "which shape to come back to when you click the floating orb"
and defaults to the small chat window — so clicking a toast while the full panel
was open **shrank it**.

Now that restore only happens when the app is actually collapsed to the orb. If
the window is already on screen it is simply raised to the front; its size is left
alone. The navigation part (open that mail, scroll to the update banner) happens
either way.
